# DevCage v0.2.0

Released: 2026-08-09

## Summary

MVP isolation runtime for AI agent development: **container-backed** `agent` / `offline` profiles, break-glass **`host`**, session lifecycle, honest network labels, and full quality gates.

## Highlights

- **Profiles**
  - `agent` — Docker/Podman, full container network (labeled honestly)
  - `offline` — Docker/Podman, `--network none`
  - `host` — break-glass host process (ephemeral `$HOME` only)
- **Commands:** `doctor`, `status`, `profile`, `run`, `shell`, `agent`, `stop [--wipe]`
- **UX:** start banner; `--wipe` on run/shell; workspace defaults to git root
- **Config:** `DEVCAGE_CONTAINER_IMAGE`, `DEVCAGE_CONTAINER_RUNTIME`, `DEVCAGE_DATA_DIR`, `DEVCAGE_SHARE_PACKAGE_CACHES`
- **Engineering:** pedantic Clippy, ShellCheck, ≥80% coverage, pre-commit

## Requirements

- Rust 1.74+ to build
- **Docker or Podman** for `agent` / `offline` (fails closed if missing)
- Image with your tools for `devcage agent` (default Alpine is a smoke base only)

## Install

```bash
./scripts/build.sh --release
./scripts/install.sh
devcage doctor
```

## Examples

```bash
devcage run -p offline -- echo hi          # needs Docker/Podman
devcage run -p host -- /usr/bin/true       # break-glass
devcage run -p offline --wipe -- uname -a
devcage stop --wipe
```

## Notes

- Host-native macOS agent binaries do **not** run inside Linux containers; use an image that includes the agent, or `host` (weak isolation).
- See [CHANGELOG.md](../CHANGELOG.md) and [docs/usage.md](../docs/usage.md).
