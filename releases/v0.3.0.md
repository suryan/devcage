# DevCage v0.3.0

Released: 2026-08-09

## Summary

Hardens isolated profiles and adds operator commands for day-to-day cage hygiene.

## Highlights

- **`untrusted` profile** — network none, always wipe, no host package caches, `--cap-drop ALL` + `no-new-privileges`
- **`offline`** — wipe by default + same hardening
- **`devcage verify`** — workspace safety, runtime presence, optional offline container probe
- **`devcage pull`** — pull `DEVCAGE_CONTAINER_IMAGE`
- **`devcage clean [--all]`** — remove session dirs
- Refuse sensitive workspaces (paths under `.ssh` / `.aws` / …)
- `scripts/e2e-container.sh` — end-to-end when Docker/Podman is installed

## Profiles

| Profile | Network | Wipe | Hardened |
|---------|---------|------|----------|
| agent | full (container) | optional | no |
| offline | none | default | yes |
| untrusted | none | always | yes |
| host | host | optional | n/a (break-glass) |

## Install / verify

```bash
./scripts/build.sh --release
./scripts/install.sh
devcage doctor
devcage verify
# with Docker/Podman:
devcage pull
./scripts/e2e-container.sh
```
