# DevCage v0.5.0

Released: 2026-08-09

## Summary

Operator observability + advisory network policy + experimental macOS Seatbelt for host-restricted agents.

## Highlights

- **Session events** — `events.jsonl` per session; `devcage logs <id>`
- **`net-allowlist` profile** — loads host list, sets `DEVCAGE_NET_ALLOWLIST` (**advisory**, not kernel-enforced)
- **`devcage init-allowlist`** + `examples/net-allowlist.txt`
- **`DEVCAGE_SEATBELT=1`** — opt-in `sandbox-exec` for `agent-host` on macOS
- Doctor reports seatbelt / sandbox-exec availability

## Examples

```bash
devcage agent --host-restricted /path/to/agent
devcage logs dc-…
devcage init-allowlist
export DEVCAGE_NET_ALLOWLIST_FILE=.devcage/net-allowlist.txt
# with Docker:
devcage run -p net-allowlist -- sh
DEVCAGE_SEATBELT=1 devcage agent --host-restricted
```

## Honesty

- Seatbelt is experimental and **off by default**.
- Net allowlist does **not** yet block TCP; tools may honor `DEVCAGE_NET_ALLOWLIST` later.
