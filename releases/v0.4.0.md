# DevCage v0.4.0

Released: 2026-08-09

## Summary

Makes AI agents usable **without Docker** via host-restricted mode, while keeping real container isolation as the preferred path.

## Highlights

- **`agent-host` profile** — ephemeral `$HOME`, secret env scrub, process on host OS
- **`devcage agent --host-restricted`** — force host-restricted mode
- **Auto-fallback** when no Docker/Podman (`DEVCAGE_AGENT_HOST_FALLBACK`, default on)
- **`devcage export`** — promote files from session home/workspace
- **[docs/agent-images.md](../docs/agent-images.md)** — container image guidance

## Isolation honesty

| Mode | Boundary |
|------|----------|
| `agent` / `offline` / `untrusted` | Linux container (needs Docker/Podman) |
| `agent-host` | Host process + ephemeral HOME + env scrub only |
| `host` | Break-glass host |

## Examples

```bash
# Without Docker (macOS agent CLIs):
devcage agent --host-restricted
# or just:
devcage agent   # falls back automatically when no runtime

# With Docker:
devcage pull
devcage agent   # true container isolation

# Export artifact from a finished session:
devcage export dc-… result.txt ./result.txt
```
