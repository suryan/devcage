# DevCage v0.6.0

Released: 2026-08-11

## Summary

Grok combined mode, generic **`devcage wrap`** for any agent, isolation probes, and tighter wrap Seatbelt.

## Highlights

- **`devcage grok`**: daily Grok under `--sandbox keys-first` + DevCage-ready env (data dir, scrub, deny host).
- **`devcage wrap -- <cmd>`**: isolate Claude / Cursor / Codex / any CLI **without** an agent-native sandbox.
- Wrap Seatbelt does **not** grant wholesale `$HOME` read; **`--net none`** denies process network.
- **`devcage limits`**: JSON probes for grok sandbox + wrap + nested offline cage.
- **`devcage init-grok --force`**: regenerate `.grok` recipes (directories only in `read_only`).

## Install

```bash
./scripts/build.sh --release
./scripts/install.sh
devcage init-grok --force   # if you use Grok combined mode
```

## Quick start

```bash
devcage grok                          # Grok
devcage wrap -- claude                # any other agent
devcage wrap --net none -- cursor-agent
devcage run -p offline -- ./sketchy.sh
devcage limits
```
