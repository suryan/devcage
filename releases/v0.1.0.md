# DevCage v0.1.0

Released: 2026-08-09

## Summary

Initial scaffold release. Isolation backends are **not** implemented yet. This version establishes the CLI surface, documentation, and (from the quality-gate work) engineering standards for the repo.

## Highlights

- CLI stubs: `doctor`, `status`, `profile list|show`, `agent`, `run`, `shell`, `stop`
- Core profile names: `agent`, `offline`, `host`
- Docs under `docs/` (PRD, architecture, usage)
- Quality gate: Clippy pedantic, ShellCheck, coverage, pre-commit

## Install

```bash
./scripts/build.sh --release
./scripts/install.sh
```

## Verification

```bash
./scripts/check.sh
devcage doctor
devcage profile list
```
